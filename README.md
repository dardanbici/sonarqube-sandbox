# SonarQube Sandbox Demo

This is a demo project to showcase static code analysis with SonarQube/SonarCloud.

##  Try it yourself:

1. **Fork this repository**
2. Edit `main.py` or `index.html` and add a small bug(e.g., use `eval()`, add duplicate code, or break HTML tags)  or just add 1 letter to the README. 
3. Open a **pull request**
4. Watch SonarCloud analyze the code and show the results

📊 View the dashboard: [SonarCloud Project](https://sonarcloud.io/project/overview?id=dardanbici_sonarqube-sandbox)
